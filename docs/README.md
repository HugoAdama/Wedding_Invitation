## Reglas Internas del Proyecto

- Iconografia: Uso exclusivo de iconos vectoriales SVG. No se utilizan emojis en el codigo ni en la documentacion.
- Tipado: TypeScript estricto sin uso de 'any' y con comprobaciones exhaustivas de nulabilidad.
- Estilos: Modulares y desacoplados bajo la carpeta de estilos, utilizando variables CSS globales y animaciones optimizadas para GPU.
